# 标题

Skill 是**做事的方法**，不是代码：domi 不会执行这里的任何内容，模型读完之后仍然通过工具一步步做，
每一步照常经过权限确认。

1. 第一步做什么，为什么
2. 第二步……
3. 什么情况下停下来问用户

写作建议：
- 步骤写成可检查的动作（「跑 `bun test` 确认全绿」），不写口号（「保证质量」）
- 写清停下来的条件，模型最容易出错的是不知道什么时候该问人
- 不要在这里放凭据或本机路径——Skill 可能被分享出去
