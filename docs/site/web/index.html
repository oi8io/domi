THREE PILLARS

缺一个，domi 就变成「又一个 agent 框架」

三个支点不是功能清单，而是 domi 与黑盒 agent 的分界线。

Soul · 会积累的人格

跨会话沉淀的人格层，人类可读的 Markdown：可 diff、可手改、可否决、可导出分享。它不是黑盒参数，而是一份你能读懂并干预的成长记录。

轨迹 · 每一步都可见

思考、工具调用、权限决策都是追加的事件流。轨迹面板让你回放任意一次会话——真实会话还能直接当测试 fixture 重放。

本地优先 · 默认拒绝

你的数据留在你的机器上。权限引擎默认拒绝，没有规则的能力不放行；每一次放行/拒绝都是一条可审计事件。

SOUL

人格是一份你能审阅的文档

Soul 是跨会话沉淀的人格层：每一轮沉淀都以人类可读的 Markdown 落盘，成长可 diff、可否决、可导出——别人导入你的 Soul 文件，就能复现你的行为差异。

  • 人类可读、可手改，不是黑盒参数
  • 每次改动都是一条可对比、可否决的记录
  • 单文件导出，他人可 import 并复现行为差异
QUICKSTART

装好、配好、开始用

适合有 CLI 习惯的开发者。从安装到第一次对话，四步。

STEP 01

安装

克隆仓库，pnpm install && pnpm build，产物是 dist/domi 单二进制。

STEP 02

初始化并配模型

domi init 生成配置；把 API key 写进 ~/.domi/secrets.yaml，或直接设 DEEPSEEK_API_KEY 之类的环境变量。

STEP 03

体检

domi doctor 逐项检查，每条问题都带一条能直接粘贴的修复命令。

STEP 04

进入对话

domi 进 TUI，第一次会自动在后台拉起 domid；浏览器里 pnpm --filter @domi/web dev 看到的是同一批会话。

~/.domi — zsh
$ domi init
# 生成 ~/.domi/config.yaml
$ export DEEPSEEK_API_KEY=sk-…
$ domi doctor
# 全部通过：daemon ✓ 模型 ✓ 权限规则 ✓
$ domi
# 进入 TUI，全屏模式，对话区自己滚动
❯ /model 换模型 · /mode 切确认模式 · /soul 看人格改动
