WHY DOMI

放心把复杂的事交给它

编程、设计、办公、定时的活、要跑很久的任务，都能交给 domi 一步步做完。

会计划，懂编排

先列计划再动手。复杂任务拆成几步，按先后依赖排好再执行。

可中断，可恢复

干活时你可以补充要求，也可以随时叫停。停下后计划和做完的部分都在，点「继续」接着做。

可跟踪，可追溯

每一步想了什么、调了什么工具、你批准了什么，都有记录。做的时候看进度，做完能回放。

可以定义人格，越来越懂你

人格是一份你能直接读、直接改的文档。它在和你的相处中慢慢学习，新学到的每一条由你决定留不留。

数据仅存本地，隐私无忧

会话、记忆、人格都存在你自己的电脑上，只发给你配置的模型。写文件、跑命令、联网，你放行了才做。

模型随你选

OpenAI、Anthropic、DeepSeek、Gemini，本地模型（Ollama），或者网关（LiteLLM、OpenRouter）。对话中途也能换。

QUICKSTART

装好、配好、开始用

目前需要会用终端，支持 macOS 和 Linux。从下载到第一次对话，四步。

STEP 01

安装

到 GitHub Releases 下载适合你电脑的包，解压后把 domi 放进 PATH。

STEP 02

初始化并配模型

domi init 生成配置模板；把 API key 写进 ~/.domi/secrets.yaml，或直接设 DEEPSEEK_API_KEY 之类的环境变量。

STEP 03

体检

domi doctor 逐项检查，每条问题都带一条能直接粘贴的修复命令。

STEP 04

进入对话

输入 domi，直接说你要做什么。干活时可以接着补充要求，按 Esc 叫停。

~/.domi — zsh
$ domi init > ~/.domi/config.yaml
# 生成配置
$ export DEEPSEEK_API_KEY=sk-…
$ domi doctor
# 全部通过：后台服务 ✓ 模型 ✓ 权限规则 ✓
$ domi
# 开始对话
❯ /model 换模型 · /mode 要不要每次问你 · /soul 看它新学到的
