### TASK-M16-001 · 会话列表排序：最后一条消息 + created_at 零值修复（= SPEC-M16-001）
- status: doing
- prd: PRD-M8-002、009（侧栏列表 / 全部会话页；拍板行见 PRD-M8 §4）
- spec: SPEC-M16-001（取舍-1…5）
- 测试先行:
  - [ ] store：列表按最后一条消息倒序——`user.input` 后落盘的会话排前；`lastMessageAt` 值正确
  - [ ] store：非消息事件（tool.call / permission / ctx.note / session.kind / model.request）不改变列表序与 `lastMessageAt`
  - [ ] store：`user.note` / `model.delta` 落盘刷新排序；多条 delta 取最后一条的落盘时间
  - [ ] store：同刻（相同 ts）两会话按创建时间倒序；无消息会话按创建时间（`lastMessageAt` = 有效创建时间）
  - [ ] store：存量 `created_at=0` 行读时用首事件时间兜底（排序与 `lastMessageAt` 均正确）
  - [ ] store：`upsert` 不带时间戳 → `created_at`/`updated_at` 为真实时钟（回归，非 0）
  - [ ] store：起标题 / 切模型的 upsert 不改变排序（`lastMessageAt` 不受影响，且不再把 `updated_at` 清零）
  - [ ] tui：会话浮层组内按 `lastMessageAt` 排；相对时间显示 `lastMessageAt`（回退 `updatedAt`）
- 实现:
  - [ ] store `sessions.ts`：list() SQL 派生列 `lastMessageAt`（消息事件最新 ts，回退有效创建时间）+ 排序；`SessionSummary` 增字段；`SessionRepo` 注入 clock 修零时间戳
  - [ ] store `sqlite-event-log.ts`：`new SessionRepo(db, this.clock)`
  - [ ] protocol `rpc.ts`：`session.list` 摘要增可选 `lastMessageAt`
  - [ ] daemon `runtime-host.ts`：list() 透传 `lastMessageAt`
  - [ ] tui `Overlays.tsx`：组内排序与 `ago` 显示改用 `lastMessageAt`（回退 `updatedAt`）；web `SessionRow` 类型补齐
  - [ ] `bun run scripts/gen-protocol-docs.ts` 重生成 docs/protocol.md；guard:api / guard:protocol 过
