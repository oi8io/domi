### 实现笔记（2026-09-15）

- 冒烟（替身模型，未入库为测试）：四种节点跑通；环在加载期报错；失败节点挡住下游、无关节点照跑；重试只动失败节点；
  手工造一个「节点 started 未完成」的运行，新 host 启动后落 `task.resume` 并重跑那个节点；
  子 agent 请求范围外能力被拒（`matchedRule: parent-scope`），父上下文里只有结论；轨迹里子会话嵌在 task.spawn 下面；
  桥接：配对码错 / 过期 / 成功、未绑定 chat 点按钮记审计、按钮审批落 `permission{source:'user', channel:'telegram'}`，消息里没有命令参数；
  通知：webhook 回 500 时任务照常完成，标题里的 key 被脱敏。
- tool 节点里 `shell.exec` 退出码非 0 或超时算失败（工具本身返回 ok，但对编排来说这一步没成）。
- 编排的节点会话（`run-….<节点>.<第几次>`）与子 agent 会话都记 `spawned_by`，默认不进会话列表；运行会话本身在列表里。
- 节点会话里的询问转到运行会话上问：人盯着的是运行会话，桥接推的也是它。
- 桥接在运行开始之后才盯上它（每 5 秒扫一次），开始那一刻的节点事件可能错过，之后的都会推——记 OPT-M5-001。
- 子 agent 的事件实时推给子会话的订阅者（`childEvents`），但 Web / TUI 目前没有「跳进子会话」的入口，只能从轨迹或长任务页的「看过程」进去。
- 桌面端：代码与配置就位（49 行），`guard:desktop` 守行数与依赖；**构建与更新从未跑过**（本机无 Rust）。
- 命令里写 `\u0000` 这类转义会在传给开发机时被展开成真字符——M4 提交里两个私有区边界字符因此是字面字符，本轮已改回转义写法。

## 缺陷登记

### BUG-M5-001 · macOS 打包报 `No matching IconType`
- status: review
- 现象：用户在 Mac 上 `pnpm --filter @domi/desktop build`，bundle 阶段失败：`Failed to create app icon: No matching IconType`
- 原因：最初 `bundle.icon` 为空；补上的 PNG 里有一张 1024×1024 的 `icon.png`。没有 `.icns` 时 Tauri 用 PNG 现拼 icns，
  1024 只接受 @2x 密度（文件名要带 `@2x`），于是找不到对应规格。另外 `createUpdaterArtifacts: true` 配着占位公钥，
  没有 `TAURI_SIGNING_PRIVATE_KEY` 时下一步也会失败
- 修复：生成 `icons/icon.icns` 与 `icons/icon.ico` 放进图标清单；更新包签名默认关，README 写明发布时怎么开；
  `src-tauri/gen/` 不进版本库
- 待确认：用户在 Mac 上重跑构建通过
