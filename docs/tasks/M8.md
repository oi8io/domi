### OPT-M8-001 · 没有 key 时 domid 起不来，设置页帮不上
- status: todo
- 现在 `domid` 用 `loadConfigOrThrow`，默认模型没有 key 就退出；第一次用的人只能回终端设环境变量或写 secrets.yaml
- 方向：domid 允许无 key 启动，会话提交时再报 `error.missing_credential`，Web 首页引导去「模型供应商」填
