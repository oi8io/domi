### BUG-M9-002 · 切到没配 key 的 provider 时，把默认 provider 的 key 发给了别家

- 发现：2026-09-18 复核（读代码）。`session.ts` `buildProvider`：`apiKey: other?.apiKey ?? m.apiKey`，注释写「没配就沿用默认的」。
