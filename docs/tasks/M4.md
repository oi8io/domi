### 实现笔记（2026-09-15）

- 记忆会话 `_memory`、审计会话 `_domid` 都以下划线开头，会话列表不显示，也不参与自动抽取。
- L3 条目 id 是「类别 + 归一化文字」的哈希：同一句话抽两次得到同一个 id，天然去重。来源编号不在本段里的条目丢掉（AC-2）。
- Soul 的「domi 写过哪一行」从 L4 事件算（`ownedLines`）；只有带 `src: L3:` 的行归 domi，导入的行（`src: import:`）与手写的行都不碰。
- 否决时文件里那一行已经被人改过，就不自动撤回，只记进 `.rejected` 并提示手动处理。
- 导入的行一律剥掉原有注释再打 `src: import:<文件名>`——别人的文件可能伪造 `src: L3:` 冒充 domi 写的行。
- `skill.load` 默认没有放行规则（INV-03 不破例）：模板里加了 `allow-skill-load`，老配置要自己加一条，否则模型会收到「权限规则拒绝」的说明。
- `domi soul review` / `import` 只在真终端里交互；管道里跑直接失败（M4-004 AC-3）。
- CLI 在本进程里开 MemoryService（domid 没跑也能用）；和 daemon 同时写 soul.md 有一个很小的竞态窗口，记 OPT-M4-001。
