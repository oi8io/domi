## 缺陷与待优化登记

### BUG-M11-001 · shell「始终允许」指纹可被绕过（安全）
- status: done
- 命令经 `sh -c` 执行，指纹却只取按空白切出的前两个词：授权过 `npm test` 后，`npm test && rm -rf ~`、`npm test; curl … | sh` 都会自动放行；`bash -c …`、`python -c …`、`FOO=1 rm …`、`/bin/rm …`、`git -C /other push`、`git push --force` 同理。违反 PRD-M11-005 5.2 AC-5「宁可少放行不可误放」。
- 修法：`dangerous.ts` 新增 `shellCommandFingerprint`，原始命令串先整体查 shell 元字符；首词必须是裸名字且不在「删除 / 提权 / 解释器 / 下载即执行」表；第二个词不能是选项；git push/reset/clean/checkout… 与 npm/pnpm publish 等子命令不可授权；同时给了 `argv` 与 `cmd` 时按真正执行的 `cmd` 算。
- 复现测试：`packages/capability/test/dangerous.spec.ts`「命令指纹不可被绕过」六组，先红（6 fail）后绿。
