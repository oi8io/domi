- 笔记: 边界标记为什么不用 `<tool_result>`：工具结果里可以原样写出这六个字符，伪造边界就是注入最直接的一招。
  换成私有区字符（U+E000/E001）并在拼装时把内容里的同名字符剥掉，**可区分性才不依赖内容老实**。
  `role: 'tool'` 本来就是结构区分，但它只在消息层成立——一旦上下文被压缩、被摊平进单条 user message，
  那个区分就没了；写在内容里的标记摊平之后还在。
  十六条载荷断言的全是权限层，**一条都不依赖模型行为**：靠「模型没被骗到」证明安全，
  等于把安全性押在一个概率上，而且每换一次模型就要重押一次。
