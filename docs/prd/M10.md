## 1. 为什么是这一章

M9 收口后，五个日常体验 / 控制缺口：

1. **会话标题没有真正接上**：`generateTitle()`（LLM 生成 + 失败降级首条输入前 40 字）在 M1 就实现且已有测试，但**生产代码从未调用**——侧边栏标题为空时显示会话 id（`titleOf` 直接回退 id），列表不可读。
2. **loop 中断条件是硬编码护栏**：`DEFAULT_LIMITS`（maxToolCalls / maxArgParseRetries / maxWallClockMs）写在 kernel，用户想调只能改代码。
3. **TUI 没有设置入口**：改语言只能改 YAML 或开 Web。
4. **思考过程（reason）不折叠**：长思维链整段铺在对话流里，挤占阅读空间。
5. **默认模型/厂商保护需要确认**：M9 已实现"默认模型是全局唯一点 + 默认 provider 不可停删"，本条只确认不新增。

## 2. 用户拍板（2026-09-19）

| # | 疑点 | 拍板 | 对本 PRD 的影响 |
|---|---|---|---|
| 1 | 标题生成的"常规手段" | **接现有的 `generateTitle()`**，不换机制 | PRD-M10-001 |
| 2 | 默认模型切换互斥 | **保持现状**；默认模型只能经「设为默认」切换，**默认模型所在的厂商不能被停用/删除** | 确认项，不新增任务 |
| 3 | loop 中断条件放哪 | **设置页新开 tab「运行时」**（用户确认命名） | PRD-M10-003 |
| 4 | TUI 设置范围 | **本轮只做语言切换** | PRD-M10-004 |
| 5 | 思考过程折叠 | **默认折叠，用户可展开** | PRD-M10-005 |

## 3. 不做什么

- **不改 `generateTitle()` 的机制**：LLM 生成 + 降级首条输入前 40 字的现有逻辑不动，只把调用时机接进运行时（PRD-M1-006 AC-1 的回退原则不回退）
- **不做 provider 级默认开关**：默认保持模型级（M9 已定，"默认是一个模型，provider 上没有默认开关"），本册不回退
- **TUI 本轮不做完整设置页**：只做语言切换入口；模型供应商、权限、Soul、插件等设置仍在 Web / YAML（M9 现状）
- **不引入思考折叠的持久化与个性化**：折叠状态会话内切换，不落盘；不按模型/会话记忆折叠偏好
- 不新增模型微调 / 自研模型（PRD-VISION §4 既有边界，不回退）

## 4. 需求条目

### PRD-M10-001 · 会话标题接入运行时

- **用户价值**：侧边栏看到可读标题而不是会话 id；标题自动生成，无需手改
- **验收标准**：
  - AC-1: 第一轮对话结束（首条 `assistant` 事件落盘后）自动调用现有 `generateTitle()`，标题写库；调用失败不影响会话继续（现有降级：空标题不产生错误）
  - AC-2: 侧边栏（Web 侧栏、TUI 会话列表）在标题为空时显示**首条用户输入前 40 字**（与 `generateTitle` 的 fallback 同一来源口径），不再显示会话 id
  - AC-3: 手动重命名仍可覆盖自动标题（Web `SessionView` 改名、协议侧 `title` 更新，M8 行为不回退）
  - AC-4: 标题生成是真实 LLM 调用，**不进 CI 门禁**（同 INV-08；测试注入模型替身，断言调用时机与降级）
- **验收方式**：`runtime/test/title-gen.spec.ts` 扩展（接入时机）+ 侧边栏渲染测试 + 手工走查
- **层级**：Negotiable
- **优先级**：P1

### PRD-M10-002 · 默认模型与厂商保护（确认项）

- **用户价值**：默认模型是唯一权威；默认厂商不会被误停误删导致新会话失去凭据来源
- **说明**：M9 已实现模型级默认互斥（`model.provider + model.name` 单一来源）与默认 provider 不可停用/删除（`ConfigWriteError(DEFAULT_PROVIDER)`）。本册**不新增实现**，仅在收口时回归验证：
  - AC-1: 点某模型的「设为默认」后，旧默认自动失效（M9 行为，回归断言）
  - AC-2: 默认模型所在的 provider 不能停用、不能删除，界面按钮禁用并说明（M9 行为，回归断言）
- **验收方式**：`packages/config/test/providers.spec.ts` / Web 设置页测试回归
- **层级**：Negotiable
- **优先级**：P1（验证为主，无新代码）

### PRD-M10-003 · 运行时护栏可配置（loop 中断条件）

- **用户价值**：不改代码就能调"这一轮跑多长 / 调多少次工具 / 重试几次"的护栏
- **验收标准**：
  - AC-1: config schema 新增 `loop` 节：`maxToolCalls`（默认 100）、`maxArgParseRetries`（默认 3）、`maxWallClockMs`（默认 600_000，单位 ms），缺省时与现有 `DEFAULT_LIMITS` 一致
  - AC-2: 设置页新 tab「运行时」：三个数字输入（含单位标注与默认值占位），保存经 `config.set` 白名单写入；非法值（非整数 / 负数 / 超过上限）被 schema 拒绝并在界面提示
  - AC-3: runtime 构造 `runTurn` 的 `deps.limits` 时从配置读取；kernel 不读配置（INV-02 不回退），只收 `LoopLimits`
  - AC-4: 修改后**下一轮开始生效**（运行中的一轮不打断）；不配置时行为与现状完全一致（回归）
  - AC-5: `domi doctor` 显示生效中的 loop 限制（来源：配置或默认）
- **验收方式**：config schema 单测 + `runtime` 单测（注入 limits 断言传入）+ 设置页走查 + 现有 loop 测试回归（确认默认值不变）
- **层级**：Negotiable
- **优先级**：P1

### PRD-M10-004 · TUI 设置：语言切换

- **用户价值**：在 TUI 里直接切中 / 英，不用开 Web 或手改 YAML
- **验收标准**：
  - AC-1: TUI 新增设置入口（命令或弹层），**仅含语言切换**：跟随系统 / 简体中文 / English，选项与 Web 设置页一致
  - AC-2: 切换写入 `ui.locale`（经 `config.set` 白名单），并提示"下次启动生效"（TUI 语言在启动时定，M9 约定不回退）；或实现即时热切换则无此提示——二选一，SPEC 阶段定
  - AC-3: 设置入口在 TUI 按键提示 / 命令补全中可见、可发现（`/` 命令补全出现新命令或 `s` 弹层）
- **验收方式**：TUI 命令解析测试 + golden 快照（en 场景）+ 手工走查
- **层级**：Negotiable
- **优先级**：P1

### PRD-M10-005 · 思考过程默认折叠

- **用户价值**：对话流不被长思维链淹没；想看细节时一键展开
- **验收标准**：
  - AC-1: Web 对话流中 `reason` 条目**默认折叠**为单行（标签 + 摘要，如"思考 · 前 N 字…"），点击展开/收起全文；折叠与展开不改变事件流（纯展示层，INV-01 不回退）
  - AC-2: TUI 对话流中 `reason` 默认折叠为单行，展开/收起有明确键位（如 Enter 或 `e`），与滚动键不冲突
  - AC-3: 折叠状态在会话内可反复切换，不持久化；工具调用 / 结果 / 权限等非 reason 条目不受影响
  - AC-4: 折叠后单行摘要的长度截断有统一口径（与 `summarizeArgs` 同一截断原则，渲染层不自行二次截断）
- **验收方式**：组件渲染测试（折叠态 / 展开态）+ TUI golden + 手工走查
- **层级**：Negotiable
- **优先级**：P1

## 5. 引用的全局不变量

| 不变量 | 影响 | 守卫 |
|---|---|---|
| INV-01 事件流只增不改 | 思考折叠是**纯展示层**，不产生 / 不修改事件 | 协议快照测试不回退 |
| INV-02 架构边界 | `loop` 配置在 runtime 读取，kernel 只收 `LoopLimits`；TUI 设置经 client-core RPC，apps 零业务逻辑 | 既有 dependency-cruiser（CI） |
| INV-08 真实 LLM 调用不进 CI | 标题生成（真实 LLM）不进 CI；测试注入替身 | CI 配置审查 + PRD-M10-001 AC-4 |
| INV-07 main 可运行 | loop 配置缺省时行为与现状一致，默认值不改 | CI 构建 + 冒烟 |
| INV-10 任务引用 PRD | 后续 SPEC / TASK 引用本册 PRD-M10-00x | 任务 lint（CI） |

**未触及**：INV-03（权限）、INV-05（Tool/Skill）、INV-06（不可信数据）、INV-09（Soul）、INV-11（数据不出本机）、INV-12（压缩）、INV-13（评估回放）。

## 6. 预算

- 估算：**约 3 天**——标题接入 0.5d · 运行时护栏 1d · TUI 语言设置 0.5d · 思考折叠 1d（Web + TUI）。
- 超出 20%（≈3.6 天）砍 P1 中优先级最低者（建议先砍 TUI 语言设置的热切换方案，退回"下次启动生效"）。
- 本册不设 P2。
