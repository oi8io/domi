## 4. 进入前钉死的判据（Invariant 级）

1. **INV-03 · 子 agent 权限只能收窄**：子会话的每次权限判断 = 父会话规则 ∩ spawn 时声明的能力清单；
   父会话没有规则（默认拒绝）或规则为 deny 的能力，子会话一律拒绝并留 `permission` 事件（matchedRule 标明是父范围拦下的）。
   「要问」的仍然问人，不因为是子任务就自动放行。
2. **INV-01 · 编排状态只在事件流里**：DAG 的每个节点开始 / 完成 / 失败、每次恢复、每次重试都是事件；
   「现在各节点什么状态」是这些事件的投影，重启后重算，不另存状态文件。
3. **INV-02 · 桥接与桌面端零业务逻辑**：`apps/bridge-telegram`、`apps/desktop` 只经 client-core 连 daemon；
   depcruise 规则覆盖这两个目录。
4. **INV-11 · 出站只发给用户配置的地方**：webhook 地址、Telegram bot 都是用户显式配置的；
   通知与桥接消息只含标题、状态、耗时与统计数字，出站前再过一遍凭据脱敏。
