## 2. 已知代价

- **沙箱只在有系统级隔离的平台上才算数**：Linux 用 bubblewrap，macOS 用 sandbox-exec。两者都没有时，
  带代码的插件**默认不运行**（fail-closed），要用户显式打开 `plugins.allowUnsandboxed` 才跑，并在 doctor 里标红。
  这台开发机是 Linux + bwrap，macOS 的 sandbox-exec 配置文件写了但**没在真机上跑过**。
- **M6-004 AC-4 的「仓库里开放 ≥5 个 good first issue」与 M6 DoD 的「外部贡献者插件」** 只有用户能做（要在 GitHub 上操作、要有外部贡献者）。
  本轮写好 CONTRIBUTING 与五个 issue 的草稿。
- **L2 题集（M6-005）要花真钱跑**：harness 与题目写好，三次重复的完整运行是验证待办（INV-08：不进 CI）。

## 4. 进入前钉死的判据（Invariant 级）

1. **INV-03 · 插件只能用 manifest 声明、且安装时用户确认过的权限**。运行时依据的是**安装时的权限快照**，
   不是磁盘上现在的 manifest；manifest 被改过（哈希不一致）的插件停用，重新安装确认后才恢复。
2. **INV-03 / INV-06 · 插件代码碰不到任何东西**：沙箱里没有网络、看不到用户文件；
   读写文件、发请求都经宿主，宿主按快照核对，越权的拒绝并落 `permission` 事件；插件返回的一切都是工具结果（带边界）。
3. **INV-05 · 执行原语仍然只有 Tool**：插件的「tool」扩展点注册出来的就是普通 Tool，照常过权限规则；
   「skill」扩展点只加 SKILL.md；「UI」扩展点只是一段在隔离 iframe 里渲染的静态页面。
4. **INV-08 · L2 不进 CI**：`scripts/check-ci-no-l2.ts` 守着。
