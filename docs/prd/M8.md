# M8 再批准门材料 —— 工作台（Web 重构 + 后端补齐）

> 状态：`SKETCH`（等用户拍板 → `COMMITTED`）· 2026-09-17
> 上位：`docs/PRD.md` v1.10 §M8 · `PRD-VISION.md` §1 §3 · `docs/adr/013`（Tailwind / shadcn 推到 parity 轮）
> 触发：用户给出已确认的高保真原型 `docs/ui-redesign/index.html` 与交接文档 `docs/ui-redesign/HANDOFF.md`，
> 并明确：**原型上有的基础功能就是要的功能，后端没有的都要补齐**（例如项目管理）。

## 1. 为什么是这一章

M3 的 Web 端是骨架：能连、能看事件流、能答确认框。之后每个里程碑往侧栏里塞一个按钮（Soul、长任务、插件、隔离会话、改动审阅），
没有信息架构，也没有「项目」这个概念——domi 做编程任务（M7）以后，这一点变成了日常使用的主要摩擦：
会话散成一列、分不清哪个在哪个仓库里跑、改配置要回终端编辑 YAML。

原型给出的是一个**工作台**：按项目组织任务、自由会话与任务分开、定时任务、设置页能直接改配置。
其中大约一半的数据 daemon 目前给不了（见 §3），所以这不是换皮，是一个完整的里程碑。

## 2. 评审结论（开工前对原型与 HANDOFF 的审查）

**原型缺陷**（直接修，不算自己发挥）

| # | 问题 | 处理 |
|---|---|---|
| D-1 | 设置页 Soul 那一块缺 `hidden`，「通用」页同时露出 Soul 内容 | 按 tab 正常切换 |
| D-2 | `.ta-primary { font-weight:50px }` 无效值 | 按 500 处理 |
| D-3 | `.session-item` / `.session-title` 写了两遍，后者 `display:flex` 让长标题省略号失效 | 合并，保留省略号 |

**原型与 HANDOFF 冲突**——用户拍板：**原型视觉为准，HANDOFF 多出的功能补上**

| 冲突 | 结论 |
|---|---|

| 插件：启停开关 vs 状态 pill | 卡片保留状态 pill，右上加启停开关 |

**设计问题**

- 深色主题下白字配 `#58a6ff` 只有 ~2.5:1。**拍板：实心按钮改用深一档的 `--accent-emphasis`**（GitHub 做法），
  选中态、链接、tab 下划线仍用亮色 `--accent`。
- 任务相关的词有 5 个（新任务 / 定时任务 / 计划任务 / 工作任务 / 长任务）。**拍板：用户面前只有「会话」和「任务」两个词**，见 §4。
- 原型没有给位置的现有功能全部保留，按原型视觉语言安放：分支、引用这一轮、删除与回收站、改动审阅、计划审批与 elicitation 表单、
  任务的重试与取消、Soul 待审阅改动、记忆检索、插件 UI 面板。确认卡默认焦点仍在「拒绝」上（INV-03）。
- 原型没有响应式；手机端不在本轮（§5）。

## 5. 不做什么

- 手机端与窄屏布局（原型没有；聊天端 / 手机同步本来就是二期）
- 通讯工具的真实接入（入口保留）
- 界面多语言：语言下拉保留，只有简体中文可选
- 从 Web 改权限规则、钩子、MCP server、安装插件——这几项等于在 daemon 那台机器上执行命令，远程 Web 客户端拿着 token 就能做，
  本轮只能在 `~/.domi/config.yaml` 里改（与 M7 钩子「只能来自用户配置」同一个立场）
- Playwright / 真浏览器 e2e（仍按 ADR-013 用 `react-dom/server` 渲染断言，parity e2e 留在最后统一做）
- 团队 / 多用户、云同步

## 6. 进入前钉死的判据（Invariant 级）

1. **INV-04 · 三端仍然只渲染**：项目归属、未读、执行形态、隔离决策、调度、用量聚合全在 daemon；
   Web 里的筛选、分组、折叠是展示状态。client-core 可以做投影（轨迹时间线），不做决策。
2. **INV-03 · 会话默认更严**：自由会话在沙盒目录里，出沙盒的读写与命令一律询问；自动隔离与「带回」仍然要人工批准（M7-006 AC-3 不变）。
3. **INV-03 · Web 不能提权**：`config.set` 只接受白名单里的键；权限、钩子、MCP、插件安装不在白名单（守卫断言）。
4. **INV-01 · 事件只增不改**：`user.input` 追加可选字段（上传附件、文件引用、技能），新增 `session.kind`、`project.assign`、`schedule.fire`，SCHEMA_VERSION 10 → 11，附 legacy fixture。
5. **INV-13 · 不新增埋点**：turns / steps / tok/s / cache 命中与用量统计都从事件投影。
6. **NFR-06 · 数据都在 `~/.domi/`**：项目表、调度表进现有 SQLite；附件在 `~/.domi/attachments/`；沙盒在 `~/.domi/scratch/`；secrets 在 `~/.domi/secrets.yaml`。
7. **INV-07 · main 一直可跑**：旧组件逐个替换，不平行新建；每一步 `pnpm web` 都能用。

## 8. 已知代价

- **会话的 cwd 语义变了**：老会话都带 domid 启动目录。迁移规则（SPEC-M8-004）：cwd 是 git 仓库或含 `AGENT.md` 的归为任务并自动建项目，其余归为会话；
  老会话不搬进沙盒（它们已经在原目录里跑过），只是以后不再加载项目上下文。
- **调度依赖 domid 常驻**：domid 没开的时间里不会触发，只在下次启动时对每个定时任务补跑最多一次。
- **Tailwind 迁移一次到位**：`styles.css` 整体换掉；TUI 不受影响。
- 规矩照旧：**先推进功能，测试验证类最后统一查漏补缺**（TASK-M8-014）。
