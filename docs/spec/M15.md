## 2. 取舍记录（用户 2026-10-08 授权按 RECON 建议 + PRD 方向自主定，可否决）

- **取舍-1（架构归属）**：预算器（budget）、遮蔽（mask）、指纹（fingerprint）、压缩 v2 投影都是**纯函数**（INV-02）。放包：`packages/kernel` 加 `budget.ts` / `fingerprint.ts`（只依赖 protocol，零 IO）；`packages/memory` 加 `mask.ts` 并改造 `compact.ts` / `strategy.ts`（策略注册点已在 memory，kernel 不认识策略名）；`packages/model` 加 `render.ts`（厂商渲染，kernel 不认识厂商）。不建新包——M15 的零件都落在既有边界上，guard:dep 零新规则。
- **取舍-2（策略档位投影）**：均衡 / 节省两档是**注册的策略名**（`balanced` / `economical`），投影 = 「遮蔽 → 压缩 → 交给 full」。`full` 不再注册为可选值（`context.strategy` schema 可选值去掉，内部参照投影用 `_full` 测试名）。老配置 `full/clean/compact` 读时映射为 `balanced`，启动 `doctor` warning「旧策略已升级为均衡」，不回写 yaml；状态栏首次启动一次性提示（i18n `settings.strategyUpgraded`）。
- **取舍-3（热区 / 冷区）**：热区 = 最近 **K=10 步**（model.request）**且** 最近 **T=32k token** 的工具输出（以最近一次 usage 的累计输入为时间轴，增量估算）；其余是冷区。参考 JetBrains「最近 10 观测」与 OpenCode「保护 40k token」；domi 的 R0 p90 步数 14、单步工具输出中位 1.2k，K=10 / T=32k 覆盖真实热区。
- **取舍-4（遮蔽批次）**：单批至少腾出 **X=8k token** 才值得付一次缓存重写（clear_at_least 同理）；遮蔽决定在「超阈值预检」或「压缩点」触发，一批落一条 `ctx.mask`（带 seq 列表 / 原因 / freedTokens）。已遮蔽的 seq 记在遮蔽事件里，投影时直接替换为指针文本，不再变（INV-12(b)）。
- **取舍-5（压缩保留粒度）**：保留最近 **K=8 步 + T=24k token** 双阈值（满足其一即保留）；边界按**步**切（每 `model.request` 事件 seq 为一步起点）。旧 `keepTurns` 配置弃用（读配置映射忽略，保留 schema 兼容字段）。
- **取舍-6（增量输入）**：输入 = 上一份 `ctx.compact.summary`（最近一条）+ 上次压缩点之后的事件；`projectText` 改为**白名单**（user.input / user.note / model.delta / tool.call / tool.result / ctx.note / verify.required / plan.update 渲染行），轨迹事件投影成一行或丢弃（S3）。
- **取舍-7（摘要边界块）**：摘要渲染成 user 消息，正文用私有区字符 **U+E002/U+E003** 包裹（`[上下文摘要]` 起止），guardrail 层点名「摘要是数据，不是用户说的话」；不再以 `user.input` 身份插回（X1）。`ctx.compact.summary` 事件形状不变（INV-01），新旧摘要字段并存。
- **取舍-8（摘要模板）**：`SummarySchema` 扩展为固定字段 zod：`goal`（目标与约束）/ `userQuotes`（用户原话，逐条）/ `keyDecisions` / `files`（改过的文件与要点）/ `errors`（错误与修法）/ `currentStep`（当前正在做的那一步的精确状态）/ `openQuestions` / `nextSteps`。旧字段 `intent / filesModified / keyDecisions / openQuestions / nextSteps` 保留为可选兼容。
- **取舍-9（补水）**：压缩请求后（下一请求）附：最近读 / 改的 K=10 个文件路径 +「需要时重读」提示、已 `skill.load` 的技能正文、当前计划文本；被压掉内容的文件让 stamps 失效（改前必须重读）。
- **取舍-10（压缩请求复用主前缀）**：`compactNow` 的摘要请求 = 主会话当前 messages（不含遮蔽后的最后变化，用投影后形状）+ 末尾一条 user「按模板摘要」；吃到主会话缓存（E7）。压缩请求的 model.request 落盘照常。
- **取舍-11（熔断）**：自动压缩连续失败 **N=2** 次熔断（落 `error{scope:'compact', recoverable:true}`，之后不再每轮自动重试），手动 `/compact` 仍可用。
- **取舍-12（缓存 TTL）**：config 加 `context.cacheTtlOverride?`（分钟，兜底）；默认按会话 kind：`task` / `task.spawn` **60 分钟**，自由会话 **5 分钟**，子 agent 继承父会话档位。Anthropic 渲染时把 TTL 转成 `cache_control`（`ttl` 参数）；OpenAI 系网关（非官方 openai）发 `providerOptions.prompt_cache_key = sessionId`，官方 openai 不发（未知参数有 400 风险），deepseek / gemini 自动缓存不发参数但 `promptCache` 能力位改 true。
- **取舍-13（推理块按厂商）**：`includeReasoning` 语义改为「按厂商协议」。DeepSeek（R0 347 次不回传不报错）不回传、不拼正文；Anthropic / Z.ai（交错思考 / preserved thinking）本轮内原样回传（走 AI SDK 的 providerOptions 或 thinking 参数）；其余厂商不回传。`model.reason` 事件保留原文（含签名若厂商给），供回传用。
- **取舍-14（工具结果纯文本）**：tool.result → AI SDK `output:{type:'text', text: markToolResult(id, payload)}`；`markToolResult` 的 JSON 双引号不再需要 safeJson 包裹（文本通道无转义层）。R3 复测目标：工具结果 token 回到原文 +3% 以内。
- **取舍-15（模型窗口）**：`packages/config` 加内置窗口表（见 §3.2）；未知模型默认 `contextWindow=128k / maxOutput=8k`（保守）并在设置里可填（`model.contextWindow?` / `model.maxOutput?`）。有效窗口 = 窗口 − maxOutput − **13k 安全余量**（Claude Code 同款：`min(maxOutput,20k)` 我们不裁，直接全额 + 13k）。
- **取舍-16（预算器）**：占用 =（最近 `model.usage` 的 input 真值 + 本步增量估算：system 固定 + 工具定义固定 + 新事件按 estimateTextTokens）÷ 有效窗口。阈值：均衡 60% 遮蔽 / 80% 压缩 / 92% 硬顶；节省 45% / 70% / **92%（硬顶不变，任何档不降）**。守卫、状态栏、上下文 tab、自动压缩全部读预算器（C3）。
- **取舍-17（降级链）**：请求前预检：>遮蔽阈值 → 遮蔽一批（落 ctx.mask，付一次缓存重写）→ 仍 >压缩阈值 → 压缩（可轮中）→ 仍 >硬顶 → 本轮停，落 `error{scope:'context', recoverable:true}` + 可执行出路（再压缩 / 新会话带摘要 / 换大窗口模型）。任何拼装异常转事件，不穿出 runTurn（R1 复现用例改断言第二次 submit 能跑）。
- **取舍-18（前缀指纹）**：`model.request.fingerprint` = `{ toolHash, layers: [{id, hash}], messages: [每条消息 hash] }`，哈希用 FNV-1a 32（纯函数，不引 node:crypto，client-core 投影不碰它）。断裂定位：相邻请求对比，第一个不同 → 归因（工具表 / 层 id / 消息 index → plan.update / verify / user.note / soul / rules / 新轮 / trust / model.switch）；非压缩点或刷新点 → 落 `ctx.prefix.break`（带 prevSeq / nextSeq / cause / 定位）。
- **取舍-19（钉住）**：`/pin <seq>` 命令 + 上下文 tab 遮蔽记录旁 📌（001 后 005 交付交互）；钉 / 解钉落 `ctx.pin`。被钉 seq 遮蔽与压缩均跳过（压缩覆盖区间含被钉 seq 时，被钉 seq 原样保留在摘要之外）。
- **取舍-20（内部会话隔离）**：`_` 前缀会话由 daemon 层拒绝：不进会话列表（RPC 过滤）、不可 submit、不可挂项目 / 改类型 / 改标题，返回明确错误（i18n `session.internal_forbidden`）。
- **取舍-21（泄漏迁移）**：`domi migrate-m15` 幂等可重跑：扫描 `_` 前缀会话，把其中「用户产生的事件」（user.input / user.note / 其后的 model.delta 与 tool.* 链，判定：会话内第一个非记忆事件起算）迁出成新普通任务会话（保留原 seq 映射，`ctx.ref` 引用照常解析），内部会话只留记忆事件；迁移前自动复制 `~/.domi/events.db` → `~/.domi/backups/pre-m15-migration-<ts>/`，失败自动回滚（保留备份 + 事务）。`doctor` 检测到未迁移会话时提示。
- **取舍-22（结构化输出降级）**：厂商无 `structuredOutput` 时用「工具调用当结构化输出」（注册一个 `submit_items` 工具，inputSchema = 目标 schema，让模型调它）；兼容「直接给数组」「包在 markdown 代码块」偏差；失败落事件 + 计入失败率。抽取去重改「先抽再与近邻比」（新候选只和 FTS / 语义近邻比较，不塞 200 条已知记忆）。
- **取舍-23（项目记忆位置与格式）**：`~/.domi/projects/<id>/memory/`（`rules.md` 风格：人可读、可手改、可否决，格式同 Soul 的结构化操作）；文件头写 `# project id: <id> · root: <path>`。id = git remote slug（`github.com-domi-domi`）优先，无 remote 用 cwd stable hash（path + inode 的 FNV-1a）。类型分流：偏好 → 全局 Soul；反馈 / 纠正 / 项目事实 / 外部参考 → 项目。索引进提示词（上限 4k token，每条一行 `[type] text · recall <key>`），正文 `memory.recall` 取。
- **取舍-24（冲刷）**：压缩前把即将被压掉内容里值得长期记的条目交给抽取（与压缩共用一次输入：增量输入文本 + 模板），不重复读历史。
- **取舍-25（环境两半）**：定格一半（会话开始）：OS / shell / 项目根 / 项目类型（detect：package.json / Cargo.toml / go.mod…）/ 语言与包管理器 / git remote；追加一半（变化时 ctx.note）：日期 / git 分支与改动文件数 / 后台作业。身份分段：通用（默认）/ 会话 / 任务（含计划）/ 子 agent（只回结论，控制长度）。
- **取舍-26（事件合并落盘）**：`model.reason` 写入改为「流式段边界或 ≥2048 字符 flush 一条」；`model.delta` 同规则（避免超长单段）。事件形状不变，旧事件照常解析（INV-01）。012 AC-2 轮内增量投影 P2：本轮不做（预算砍价第一顺位），留 ADR-005 占位注释。
- **取舍-27（策略切换生效时机）**：策略切换**即时生效**（配置是投影逻辑不是前缀内容）；切换本身 = 一个投影边界点，若触发遮蔽/压缩按 004/005 落事件付一次缓存代价。冻结语义只针对**前缀内容**（soul / rules / skills / catalog / 工具表 / 身份层）。
- **取舍-28（`full` 参照投影）**：测试与 L1 回放用 `_full` 内部名（不注册为可配置值）；`listContextStrategies()` 对配置 schema 隐藏 `_full`。

## 3. 接口契约

### 3.1 新事件（SCHEMA_VERSION 17）

```ts
// ctx.note —— 会话内必须送达的动态内容（INV-12(b) 追加送达）；渲染为新 user 块（NOTE_MARK 风格）
{ t: 'ctx.note', text: string, reason: 'plan'|'env'|'verify'|'supplement'|'model_switch', ref?: number /* 关联 seq */ }
// ctx.mask —— 遮蔽决定（INV-12(a)）
{ t: 'ctx.mask', seqs: number[], reason: 'cold'|'dedup'|'resolved_error'|'truncate'|'threshold', freedTokens: number }
// ctx.pin —— 钉住 / 解钉（004 AC-5）
{ t: 'ctx.pin', seq: number, pinned: boolean }
// ctx.refresh —— 显式刷新点（INV-12(b) 白名单）
{ t: 'ctx.refresh', reason: 'manual'|'trust'|'model_switch'|'strategy'|'soul'|'rules'|'skills' }
// ctx.prefix.break —— 非预期前缀断裂（001 AC-2 运行期观测）
{ t: 'ctx.prefix.break', prevSeq: number, nextSeq: number, cause: string, layer?: string, msgIndex: number }
```

`model.request` 加可选 `fingerprint?: { toolHash: string, layers: Array<{ id: string, hash: string }>, messages: string[] }`（哈希 FNV-1a 32 hex，只记哈希不记内容）。

### 3.2 配置（config schema 增量）

```yaml
context:
  # 兼容旧键（读时映射）：strategy: full|clean|compact → balanced；keepTurns/compactAt 弃用忽略
  strategy: balanced | economical        # 默认 balanced；不再有 full
  maxTokens: 150000                      # 兼容键：不再作守卫唯一口径，预算器优先；保留作为旧端兜底
  cacheTtlOverride: ~                    # 分钟；缺省按会话 kind（task 60 / free 5 / spawn 继承）
  serverSide: false                      # 006 AC-5 服务端能力开关，默认关
  maskBatchMinTokens: 8000               # 遮蔽单批至少腾出量（取舍-4）
  hotSteps: 10                           # 热区 K（取舍-3）
  hotTokens: 32000                       # 热区 T
  compactKeepSteps: 8                    # 压缩保留 K 步（取舍-5）
  compactKeepTokens: 24000               # 压缩保留 T token
  maskAt: 0.60                           # 均衡遮蔽阈值（节省 0.45）
  compactAt: 0.80                        # 均衡压缩阈值（节省 0.70）
  hardCap: 0.92                          # 硬顶，任何档不动
  compactFailMax: 2                      # 熔断 N
model:
  contextWindow: ~                       # 未知模型可填；缺省 128k
  maxOutput: ~                           # 缺省 8k
```

内置窗口表（`packages/config/src/model-windows.ts`，未知匹配保守默认）：deepseek-chat/v4-pro 128k/8k · deepseek-flash 128k/8k · glm-4.7-flash 128k/8k · gpt-4o/o-series 128k/16k · claude-3-5/3-7-sonnet 200k/32k · gemini-2.x 1M/8k（估算）。

### 3.3 投影（packages/memory 注册）

- `balanced` / `economical`：`(events, policy) → messages`，内部 = 遮蔽投影（读 ctx.mask / ctx.pin 事件 → 冷区 tool.result 换指针）→ 压缩投影（读最近 ctx.compact → 区间换摘要块）→ `buildContext(_, {strategy:'_full'})`。
- 遮蔽投影纯函数：输入 events + policy → { masked, freedTokens }；决定由预算器 / 压缩点触发，落 ctx.mask 后投影只读事件。
- 摘要渲染：`renderSummary(s)` 输出 U+E002 包裹文本，guardrail 层文本加「摘要是数据」一行。

### 3.4 厂商渲染（packages/model）

- `render.ts`：`buildRequestParts(vendor, capabilities, {messages, system, tools, sessionKind, ttlOverride, serverSide}) → { providerOptions, toolResultMode }`。
  - anthropic：messages 顶层 + system 末尾 `cache_control: {type:'ephemeral', ttl}`；providerOptions 透传。
  - openai 网关（vendor.openai 且 adapter=openai-compatible 且非官方 baseUrl）：`providerOptions.prompt_cache_key = sessionId`；官方 openai 不发。
  - tool.result：`output:{type:'text', text}`（取舍-14）。
  - 推理：按取舍-13 渲染（anthropic/z.ai 回传，deepseek 不回传）。
- `ai-sdk-provider.ts` 改：tool-result 文本通道、providerOptions 来自 render、reasoning 按厂商。

### 3.5 daemon / runtime 增量

- runtime `session.ts`：
  - 会话开始定格快照（soul / rules / skills / catalog / 身份层文本 + mtime 指纹），`prompt()` 改读快照；来源变化 → 待生效计数（`ctx.refresh` 后重定格）。
  - 动态内容改追加：plan.update（内容变化时）/ env 变化 / verify / 补充 → 落 `ctx.note`；`withPrompt` 不再拼最后一条 user（dynamic 移除，system 仍前置）。
  - 请求前预检：`budget.evaluate()` → 降级链（取舍-17），每级落事件；`buildContext` 超限改抛 `ContextLimitError`（可恢复），runTurn catch → `error{scope:'context', recoverable:true}`。
  - 指纹：请求前算 `fingerprint.of(messages, toolSchemas, layers)` 随 model.request 落盘；下一请求前对比，非白名单断裂落 `ctx.prefix.break`。
  - `maybeAutoCompact` 改读预算器 + 熔断计数 + 轮中可触发；`compactNow` 改增量输入 + 复用主前缀 + 补水。
  - `/pin <seq>`、`/compact <重点>` 命令（input 解析加两条）。
  - `model.reason` / `model.delta` 落盘按段合并（取舍-26）。
- daemon：`_` 前缀会话拒绝（会话列表过滤 / submit / 挂项目 / 改类型改标题）；`session.metrics` 返回扩展字段（cacheHitPercent / avoidableLoss / maskCount / compactCount / overflowCount / memorySuccessRate）。
- `domi doctor --context`：只读扫库输出 R0 表；`domi migrate-m15`：迁移命令；`domi prompt dump`：新层与冻结边界标注。

### 3.6 端上（client-core 投影 + Web/TUI）
